Bastion AI · Sovereign Stack01 — Overview

The problem

Best-in-class AI and data sovereignty usually pull in opposite directions.

The pull

The best models live in the cloud

Frontier capability is a hosted API call away. The fastest path to value is to send your prompt — and the context around it — off-premises to a provider you don't control.

The constraint

Regulated data can't leave the boundary

PII, customer records, board decks, jurisdictional data. Once raw text — or an embedding of it — crosses the line to be processed, the sovereignty posture is already lost, and no contract clause recovers it.

Most architectures make you choose. Bastion AI is built so you don't have to.

The tension02

The thesis

Bring the intelligence to the data — governed — instead of sending the data to the intelligence.

In-boundary models

Sensitivity of the request and its context — public, internal, confidential, regulated. Presidio PII detection runs natively in ~19 ms.

Zero-egress RAG · L607

The sovereignty model — honestly drawn

Streaming is transport, not sovereignty. Two gates are what actually hold the line.

Gate 1

Local embeddings

Raw text is vectorized on-box and never shipped out to be embedded. And note: vectors are not safe anonymization — embedding-inversion can reconstruct text, so the embedder itself must stay inside the boundary.

Gate 2

The governed prompt

Retrieved chunk text rides inside the augmented prompt. Bastion governs that prompt — so confidential or regulated context forces an in-boundary model, and can never be carried to the cloud.

What LucidLink is — and isn't
It minimizes at-rest copies and adds client-side encryption. That is real value. It is not sovereignty by itself — the two gates above are.

Leak model · design decision08

Provenance & continuity

Git for agent memory — so you can prove, roll back, and erase.

RVF + agenticow

The knowledge store is a single-file HNSW index (RVF), witness-chained for provenance, wrapped by agenticow — copy-on-write vector branching.

  • Branch a base memory in ~0.5 ms / 162 bytes, independent of base size
  • Exact read-through: parent ∪ edits, child wins on collision
  • lineage() traces every vector's origin

Why it matters for sovereignty

  • GDPR right-to-erasure — drop a branch to surgically remove a source, with the lineage to prove it's gone
  • Rollback — quarantine a poisoned ingest without re-indexing the world
  • Honestly scoped — a single ANN index that spans the COW boundary is roadmap, not yet shipped
